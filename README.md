# Website HuManas

## Overview

Web application that showcases HuManas tutoring services, methodology, and contact channels.

## Requirements

- Node.js 18 or newer
- npm 9 or newer (or an equivalent package manager)

Install dependencies by running `npm install` inside the `humanas-website` folder.

## Available scripts

- `npm run dev`: starts the Vite development server at `http://localhost:5173`.
- `npm run build`: generates an optimized production build in `dist/`.
- `npm run preview`: serves the generated build locally for quick verification.
- `npm run lint`: runs ESLint on the project.

## Project structure

- `src/`: React components, styles, and static assets.
- `public/`: files served directly without processing.
- `dist/`: build output generated by `npm run build`.

## Deployment

The project can be deployed to any static hosting provider (Netlify, Vercel, GitHub Pages, etc.).

### Generic static hosting

1. Run `npm run build`.
2. Upload the contents of the `dist/` folder to your hosting provider.

### Vercel

1. Push the repository to GitHub/GitLab/Bitbucket and import it on Vercel.
2. When prompted for the project root, select `humanas-website/`.
3. Use the defaults provided in `vercel.json` (build command `npm run build`, output directory `dist/`).  
   O arquivo também aplica um rewrite para que o React Router funcione em rotas internas.
4. Deploy. Subsequent pushes to the default branch will trigger automatic redeploys.
